# API de recetas con validación

Proyecto de la semana 3: API REST con Express, TypeScript y validación de datos con Zod.

## Funcionalidades

- CRUD de recetas en `/api/v1/recipes`
- Validación de creación y actualización con Zod
- Middleware de logging
- Respuestas centralizadas para errores `400` y `404`
- Almacenamiento en memoria

## Instalación y ejecución

```bash
pnpm install
pnpm dev
```

## Construcción

```bash
pnpm build
```
